# 4단계 대사 검토 (녹음 전)

대사는 `src/audio/step4Script.js` 한 파일에 있어요. 아래는 예시이고, 풀이 말은 숫자마다 따로 녹음해야 해요.

## 1. 지금 대사 (예시)

### 사바나
- 바나나 묶음 세기 문제: 바나나가 모두 몇 개일까? 묶음부터 눌러서 세어 봐!
-   풀이(73): 열 개 묶음이 일곱 개, 낱개가 세 개. 모두 73이야!
-   풀이(80): 열 개 묶음이 여덟 개, 모두 80이야!
- 10개 모아 묶기 문제: 낱개를 눌러서 열 개를 모아 묶어 봐! 그다음 모두 몇 개인지 맞혀 봐!
-   풀이(64): 낱개 열 개를 묶으면 묶음 하나가 돼! 열 개 묶음이 여섯 개, 낱개가 네 개. 모두 64야!
- 숫자판 문제: 숫자판의 물음표 칸에 들어갈 수는?
-   옆칸 풀이(47,46): 46은 다음 칸, 47이야!
-   위아래 풀이(57,47): 57은 바로 위 칸이 10 작은 수, 47이야!
-   위아래 풀이(37,47): 37은 바로 아래 칸이 10 큰 수, 47이야!
-   아무 칸 힌트: 앞뒤 칸과 위아래 칸을 잘 봐!

### 숲속
- 10 먼저 채우기 문제: 먼저 열 칸을 채우고, 남은 도토리를 더해서 모두 몇 개인지 맞혀 봐!
- 식만 문제(공통): 식을 풀어 봐! 열을 먼저 만들면 쉬워.
- 도토리 더하기 그림 문제: 도토리를 모두 합치면 몇 개일까?
-   풀이(8+5): 8에 2를 주면 10, 3이 남아서 13이야!
-   풀이(9+6): 9에 1을 주면 10, 5가 남아서 15야!
- 세 수 더하기 문제: 세 수를 더해 봐! 합이 열이 되는 짝꿍을 먼저 찾으면 쉬워.
-   풀이(3,7,4): 3 더하기 7은 10, 10 더하기 4는 14야!

### 바닷가
- 수직선 문제: 수직선에서 거꾸로 뛰어 봐! 열까지 먼저 뛰면 쉬워.
-   풀이(13−5): 13에서 10까지 세 칸 뛰고, 두 칸 더 뛰면 8이야!
- 물고기 빼기 그림 문제: 물고기가 헤엄쳐 가고 나면 몇 마리 남을까?
- 빈칸 그림 문제: 조개가 모두 몇 개 되려면 몇 개가 더 필요할까?
- 빈칸 식 문제: 빈칸에 들어갈 수는?
-   풀이(8+□=13): 8에서 10까지 2, 10에서 13까지 3, 합치면 5야!

### 공룡
- 뛰어 세기 문제: 발자국을 따라 뛰어 세어 보자! 물음표 자리에 들어갈 수는?
-   풀이(10씩 → 54): 10씩 뛰어 세면 54가 와!
-   풀이(5씩 → 35): 5씩 뛰어 세면 35가 와!
- 짝수·홀수 그림 문제: 공룡 알을 둘씩 짝 지어 봐! 짝수일까 홀수일까?
- 짝수·홀수 숫자 문제: 이 수는 짝수일까 홀수일까?
-   짝수 풀이: 둘씩 짝을 지으면 남는 게 없어서 짝수야!
-   홀수 풀이: 둘씩 짝을 지으면 하나가 남아서 홀수야!
- 누가 더 커 문제: 더 큰 수를 눌러 봐!
-   풀이(십의 자리): 십의 자리를 먼저 봐! 74가 더 커.
-   풀이(일의 자리): 십의 자리가 같으니까 일의 자리를 봐! 47이 더 커.

### 시장
- 시계 읽기 문제: 시계 바늘을 보고 맞는 시각을 골라 봐!
- 시계 돌리기 문제: 짧은 바늘을 돌려서 시계를 맞춰 봐!
- 하루 일과 문제: 하루 일과 시각이야! 시계를 보고 맞는 시각을 골라 봐!
-   풀이(7시 정각): 긴 바늘이 12를 가리키고 짧은 바늘이 7을 가리키니까 일곱 시 정각이야!
-   풀이(7시 반): 긴 바늘이 6을 가리키면 반이야! 일곱 시 반이야.
-   풀이(12시 반): 긴 바늘이 6을 가리키면 반이야! 열두 시 반이야.
-   풀이(1시 정각): 긴 바늘이 12를 가리키고 짧은 바늘이 1을 가리키니까 한 시 정각이야!
- 일과 문장: 아침을 먹어요 / 학교에 가요 / 점심을 먹어요 / 간식을 먹어요 / 책을 읽어요 / 잠을 자요
- 동전 세기 문제: 동전을 모두 합치면 얼마일까?
-   풀이: 차례로 더하면 50원, 60원, 70원, 80원! 모두 80원이야.
- 물건 사기 문제: 가격표를 보고 딱 맞게 동전을 내 봐!
-   풀이(70원): 70원은 50원 동전 한 개, 10원 동전 두 개이면 돼!

## 2. 어색한 곳 (고치면 좋은 것)
1. 숫자판 풀이: "57은 바로 위 칸이 10 작은 수, 47이야!" → "57의 바로 위 칸은 10 작은 수, 47이야!"
2. 숫자판 풀이: "46은 다음 칸, 47이야!" → "46 다음 수는 47이야!"
3. 시계 풀이(7시 반): "…반이야! 일곱 시 반이야." → "긴 바늘이 6을 가리키면 반이야! 일곱 시 반!"

## 3. 녹음 개수 (대략)
| 말 | 가짓수 |
|---|---|
| 문제 말 (숫자 없음) | 약 25 |
| 시계 풀이 | 24 |
| 받아올림·받아내림·빈칸 풀이 | 약 100 |
| 세 수 더하기 풀이 | 약 80 |
| 바나나·묶기 풀이 (51~100) | 약 100 |
| 숫자판 풀이 (옆칸·위아래) | 약 340 |
| 뛰어 세기 풀이 | 약 230 |
| 누가 더 커 풀이 | 약 100 |
| 동전·물건 사기 풀이 | 약 60 |
| 합계 | 약 1,000 (목표 400~500보다 많음) |

## 4. 줄이는 방법 (제안)
- 숫자판·뛰어 세기·누가 더 커 풀이는 숫자 없는 통문장으로 바꿔요. 숫자는 화면에 이미 보여요. 예: "십의 자리가 큰 쪽이 더 커!" (약 670개 → 약 10개)
- 바나나·묶기 풀이도 숫자 없이: "열 개 묶음이 몇 개인지 세고, 낱개를 더해 봐!" (약 100개 → 2개)
- 세 수 더하기 풀이: "합이 열인 짝꿍을 먼저 더하고, 남은 수를 더해!" (80개 → 1개)
- 받아올림·받아내림·빈칸 풀이와 시계 풀이는 숫자를 넣은 통문장으로 그대로 둬요 (연산 풀이는 통문장이라는 규칙).
- 이렇게 하면 새 녹음이 약 250개 (숫자 1~100 읽기 포함하면 약 350개)예요.

## 5. 먼저 시험 녹음할 3개 (이어 붙인 소리 확인용)
1. 8에 2를 주면 10, 3이 남아서 13이야!
2. 긴 바늘이 12를 가리키고 짧은 바늘이 7을 가리키니까 일곱 시 정각이야!
3. 십의 자리가 큰 쪽이 더 커!

## 6. 적용 결과
위 제안(숫자 없는 풀이 문장, 시계 풀이 고침)을 `step4Script.js`에 적용했어요. 숫자판 풀이는 숫자 없는 문장으로 바뀌어 1·2번 고침은 필요 없어졌어요. 위 1번 목록의 예시는 고치기 전 문장이에요.
